隐私政策

你的日常记录，
保留在你的设备中。

生效日期：2026 年 10 月 12 日 · 开发者：Will Li

本政策适用于记好（I Did It）iPhone 与 Apple Watch 应用，以及本支持网站。

应用中的数据

事项名称、备注、可选照片与熟悉的声音录音（在支持此功能的版本中）、计划、偏好和完成记录保存在你的设备中。开发者没有运行接收这些记录的应用服务器，也不会自动收到这些记录。应用不要求注册账号，不包含广告、跟踪或第三方分析 SDK。

配对的 iPhone 与 Apple Watch 使用 Apple 的 WatchConnectivity 服务交换应用数据。系统设备备份可能按你的设备设置包含应用数据；这与开发者提供的云端服务不同。

由你控制的权限

  • 麦克风与语音：仅在你启动“语音记一下”后开始识别，应用请求本机识别，不保存这类识别音频；离开页面即停止。识别内容经你核对后才保存。键盘听写和 Siri 是独立的 Apple 功能，由系统设置控制。
  • 熟悉的声音（1.1 及以后版本）：你可在手机单独录制最多30秒的声音，试听后明确保存到事项。请先征得说话者同意。已保存录音保留在设备中，同步到配对手表，并包含在完整备份中；仅在主动点击时播放。你可在编辑事项时更换或移除录音，保存后同步移除。已导出备份及恢复副本需另行管理。
  • 设置防误改（1.1 及以后版本）：设备使用者验证由系统处理，应用只收到成功或失败结果，不会得到设备密码或生物识别数据。此功能用于防止误改设置，不隐藏历史，也不限制日常记录。
  • 照片与相机：你选择或拍摄的照片会随事项保存在设备中，可能同步到配对手表，并包含在你导出的备份中。
  • Apple 健康：在支持的系统版本上，只读取你授权的药品名称。选中的名称在保存事项时写入备注。应用不会把完成记录写入健康，也不会将健康数据用于广告。
  • 通知与朗读：本地通知可能显示事项名称；朗读会通过系统音频输出播报事项信息，附近的人可能看到或听到。

你可以在系统设置更改权限，并在适用时继续使用手动输入。

备份、保留与删除

记录会保留到你删除为止。导出备份包含事项、照片、已保存的录音（如有）和历史记录，应用不会为导出文件加密；保存或分享位置由你选择。恢复备份会替换应用数据，并事先保留一份本机恢复备份。

“清除所有数据”会删除应用中的事项和记录，并在配对手表连接后同步删除。已经导出的文件、独立保存的恢复文件，以及系统设备备份，需要在各自的存储位置另外管理。

主动分享报告

在支持报告的版本中，你先选择日期和事项、预览文字，再打开系统分享面板。报告包含所选事项名称、状态、时间，以及标注为本人记录还是家人代记；不含照片、录音或备注。应用不会自动把报告发送给家人或开发者。

联系支持时

发送到 weilifilm@gmail.com 的邮件包含你的邮箱地址及你主动提供的内容。这些信息用于回复你的请求，并由邮件服务商处理。非必要请不要发送敏感事项详情或照片。你可以向同一邮箱提出删除支持邮件的请求。

本网站

这是静态支持网站，没有添加分析工具、广告、表单或跟踪 Cookie。网站托管在 GitHub Pages，托管商出于安全目的记录访问者的 IP 地址。托管商的数据处理方式请参阅 GitHub 隐私声明。

更新与联系

数据处理方式发生变化时，本政策会相应更新。上方生效日期标明当前版本。如有隐私问题，请通过 weilifilm@gmail.com 联系 Will Li。
